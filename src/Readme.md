- MNIST dataset has been chosen for implementing the paper (Semi-Supervised learning system using Reinforcement Learning)
- Following are major sections of my code:
  - Using a Deep Q-Learning Agent as RL agent to assign pseudo-labels to unlabeled MNIST samples.
  - Training a CNN classifier (Simple CNN) using both:
    - A small subset of truly labeled data
    - Pseudo-labels generated by the RL agent
  - Using RL rewards to improve pseudo-label selection quality.
- Simple CNN is used as model to extract softmax probabilities, entropy and also to train on labels
- DQN is used as RL agent
